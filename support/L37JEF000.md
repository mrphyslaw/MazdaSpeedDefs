# L37JEF000 support notes

Definition for the supplied CX-7 2.3 DISI Turbo layout. The vehicle is reported
as a 2007 automatic. Sales market and factory provenance remain unconfirmed.

Map locations, lookup dimensions, native axis storage and diagnostic records
were checked against this image. The definition uses the same tuner-focused
coverage as the existing Gen 1 definitions. This is an offline verification;
vehicle testing remains pending.

Knock Retard Decrement Step Size is shared by both recovery paths in this
layout, so it is exposed once. Gear Ratio controls are ECU calculation inputs;
they do not change transmission hardware or program the transmission controller.

Timing units retain the traced software schedule: a nominal 0.5 ms interrupt,
5 ms main dispatch and five rotating slots. Injection phase updates use a
25 ms slot. Pulse timing uses the native 0.004 ms count. Hardware clock
accuracy and scheduling overruns are outside the offline checks.

Use the supplied launcher and MazdaL37JChecksum.jar. Saving automatically
corrects the big-endian program sum over 0x48000 through 0xFFFFF to 0x5AA55AA5,
using the reserved word at 0x48000. Edits below that range do not change the
program checksum. Exact identity, image size, markers and native checksum
layout must match before correction is allowed.

Disable Decel Fuel Cut - Code Patch changes a branch instruction. Use its
named states to apply or restore the patch.
