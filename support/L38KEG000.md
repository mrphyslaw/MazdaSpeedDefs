# L38KEG000 support notes

Support for the reported 2007 Canadian-market Mazdaspeed6 with a six-speed
manual transmission. The supplied image's factory provenance is unverified.

The program region matches the L38KEH000 reference exactly. The definition
uses the same verified map addresses, dimensions, axes and control encodings,
with values read from the matching image.

Use the supplied launcher and the current MazdaL38KChecksum.jar. The program
checksum covers 0x48000 through 0xFFFFF and automatically corrects on save
using the reserved word at 0x48000. Calibration edits below that region
leave the program checksum word unchanged.

The Disable Decel Fuel Cut option changes an ECU branch instruction. Use
the definition's named states to apply or restore that code patch.
