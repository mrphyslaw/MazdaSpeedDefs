# L3M6EG000 support notes

Experimental support for the matched Mazda6 software layout. Use the supplied
launcher with ordinary RomRaider to load the checksum module.

The definition follows the earlier load-control and injection-timing strategy.
Gear limits and injection timing reflect this firmware's available banks.
Extended-range firmware changes are outside this definition.

The program checksum covers `0x3F000` through `0xFFFFF`. RomRaider automatically
repairs it on save using reserved padding at `0xFFFF4`; the executable code at
the beginning of the covered region and the fixed image trailer are preserved.
Calibration edits outside that range do not change the correction word.

The deceleration fuel-cut option is a code patch. Its two-byte encoding is
specific to this software and should be selected through the definition.

Validation includes native lookup and diagnostic checks, editor loading,
edit/save/restore checks and the required automatic-checksum save audit.
Offline verification does not establish operation on a physical ECU.
